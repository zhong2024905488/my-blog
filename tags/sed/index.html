实验二：Linux 文件管理及文件过滤实践

实验目的 掌握文件管理操作（创建、复制、移动、删除、链接）； 掌握 Vim 编辑器的基本使用（进入、编辑、保存、查找、替换）； 掌握 grep、sed、awk 三种文本过滤工具的基本用法； 理解正则表达式与管道，并能组合使用这些工具完成检索、过滤与统计。 实验环境 Ubuntu 20.04，Vim 8.x，GNU grep / sed / awk。 实验内容与步骤 一、文件管理操作 mkdir -p ~/lab2/demo touch ~/lab2/demo/file1.txt cp ~/lab2/demo/file1.txt ~/lab2/demo/file2.txt mv ~/lab2/demo/file2.txt ~/lab2/demo/file2.bak rm -i ~/lab2/demo/file2.bak 硬链接与软链接对比： ln ~/lab2/demo/file1.txt ~/lab2/demo/hard.txt # 硬链接 ln -s ~/lab2/demo/file1.txt ~/lab2/demo/soft.txt # 软链接（符号链接） ls -li ~/lab2/demo 执行后可以看到：hard.txt 与 file1.txt 的 inode 号相同、链接计数为 2；soft.txt 是独立 inode，内容指向源文件路径。删除源文件后，硬链接仍可访问，软链接则失效（出现红色闪烁的断链）。 二、Vim 编辑器练习 vim ~/lab2/demo/note.txt 在 Vim 中依次练习：按 i 进入插入模式输入内容，按 Esc 回到普通模式，:wq 保存退出；用 /关键字 查找、:%s/旧/新/g 全文替换、dd 删除整行、yy 复制整行、p 粘贴、u 撤销。 ...

## 实验目的

- 掌握 VirtualBox 虚拟机软件的基本使用方法；
- 熟悉 Ubuntu 系统的安装流程；
- 学会通过克隆、导出 OVF 快速部署多台 Linux 系统；
- 掌握 SSH 远程连接与 scp 文件传输；
- 掌握常用的目录操作与文件操作命令。

## 实验环境

VirtualBox 7.x，Ubuntu 20.04，宿主机 Windows，虚拟机网络采用 NAT 与桥接两种模式对比测试。

## 实验内容与步骤

### 一、安装虚拟机软件并新建第一台 Linux 虚拟机

在 VirtualBox 中新建虚拟机，分配 2 GB 内存、20 GB 动态扩容磁盘，挂载 Ubuntu 镜像完成安装。安装前需在 BIOS 或虚拟机设置中开启虚拟化支持（VT-x/AMD-V），否则会提示无法启动。

### 二、配置网络并验证

Ubuntu 安装完成后先确认网络状态：

```bash
ip -c a
hostname -I
ping -c 3 192.168.1.1
```

尝试把网卡从 NAT 改成桥接模式后，虚拟机可直接从局域网 DHCP 获得 `192.168.x.x` 地址，宿主机能够 ping 通；而 NAT 模式下虚拟机只能单向访问外网，宿主机需要配置端口转发才能反向访问。

### 三、基本命令练习

```bash
pwd                 # 查看当前目录
ls -l /etc          # 以长格式列出目录内容
cd ~                # 回到当前用户家目录
mkdir -p lab/a/b    # 递归创建多级目录
cp -r lab lab_back  # 递归复制目录
mv a.txt b.txt      # 重命名文件
rm -i b.txt         # 删除前要求确认
cat /etc/hostname   # 查看文件内容
df -h               # 查看磁盘使用情况
free                # 查看内存使用情况
```

### 四、克隆与 OVF 导入导出

- **克隆**：在 VirtualBox 中右键虚拟机选择“复制”，可生成完整克隆或链接克隆，链接克隆速度快但不独立。
- **OVF 导出**：文件 → 导出为 OVF/OVA，单文件标准格式，可跨虚拟化平台迁移。

```bash
ssh zhong@192.168.56.102      # 远程登录第二台虚拟机
scp lab/a.txt zhong@192.168.56.102:~/   # 上传文件
```

## 遇到的问题与解决办法

1. 两台虚拟机互相 ping 不通：原因是网卡模式不一致，统一改为桥接并重启网络后恢复。
2. 克隆后提示 MAC 地址冲突：在虚拟机设置的网络高级选项中重新生成 MAC 地址。
3. 启动报“虚拟化未开启”：进入 BIOS 打开 VT-x，或在虚拟机设置中勾选虚拟化引擎相关选项。

## 实验总结

本次实验完成了 Ubuntu 虚拟机的安装、网络配置与远程连接，理解了桥接、NAT、仅主机三种网络模式的差别，掌握了 `ssh`、`scp` 以及目录文件的基本操作命令。体会到虚拟机非常适合学习 Linux，快照可以规避误操作风险，网络故障应优先排查网卡模式、IP 与防火墙。
